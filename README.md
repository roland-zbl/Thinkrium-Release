# Thinkrium Releases 🚀

Official public binary releases and installers for **Thinkrium** — the local-first knowledge operating system for deep thinkers.

## 📥 Downloads

Visit the [**Releases**](https://github.com/roland-zbl/Thinkrium-Release/releases) page to download the latest installers for:
- 🍎 **macOS**: `.dmg` installer & `.zip` archive (Apple Silicon)
- 🪟 **Windows**: `.exe` setup installer
- 🐧 **Linux**: `.flatpak` universal package

## 📖 About Thinkrium
Thinkrium is an open-source, local-first personal knowledge operating system integrating RSS feeds, highlights, structured conceptual entries, daily journaling, and contextual material sidecars.

Main repository: [roland-zbl/thinkrium](https://github.com/roland-zbl/thinkrium)
